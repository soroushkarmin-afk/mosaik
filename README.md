# Mosaic — Standalone Edition

Mosaic is a no-build, no-install educational set-theory puzzle. It uses plain HTML, CSS, and JavaScript—no React, npm, bundler, or server is required.

## Run it

1. Extract the ZIP archive.
2. Open `index.html` in a current browser (Chrome, Firefox, Edge, or Safari).
3. Play. Your progress is saved in that browser using `localStorage`.

You can also serve the folder using any static web server, but that is optional.

## Files

- `index.html` — complete page structure and interactive Venn diagram markup.
- `styles.css` — layout, colors, typography, responsive rules, and component styling.
- `app.js` — puzzle rules, levels, scoring, timer, hint/undo/restart, daily puzzle, streak, themes, sound effects, settings, and local save state.

## Included mechanics

- Six progressive levels and four Venn regions: A only, B only, overlap, and outside both.
- Logical target expressions, move limits, timer levels, score/XP, best score, completed levels.
- Hint penalty, undo last move, restart confirmation, pause/resume, success/failure feedback.
- Date-based daily puzzle and local streak tracking.
- Theme collection and unlocks (Garden, Golden hour, Lavender fields).
- Optional browser-generated sound effects and simple low-volume background tone.
- Responsive desktop and mobile layout, keyboard focus styles, and reduced-motion support.

## Notes

This standalone edition intentionally has no account system, Google OAuth, cloud sync, or database. All progress is stored locally in the current browser profile. The Google Fonts import is optional; if offline, the browser falls back to system fonts.
